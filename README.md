# DevOps Training Programme

## Overview

This programme introduces the core principles, practices and tools used in **DevOps**.

DevOps brings **development, operations and automation** together to enable teams to build, test, deploy and manage software reliably.

Key skills covered include:

* ☁️ Azure & cloud fundamentals
* 🐧 Linux & Bash
* 🔄 Git & CI/CD
* 🔧 Jenkins
* 🏗️ Terraform & Infrastructure as Code
* 🐳 Docker & containers
* ☸️ Kubernetes
* 🤖 Automation
* 🔗 Integration and troubleshooting

The programme progresses from individual technologies to a complete DevOps workflow.

---

## Training Schedule

### 01 — Azure Fundamentals

Introduction to cloud computing and Azure.

**Focus:** Azure Portal, Azure CLI, subscriptions, tenants, resources, resource groups and identity.

### 02 — Bash Scripting & Automation

Develop Linux command-line and automation skills.

**Focus:** Bash, variables, loops, conditionals, functions, scripting and CLI automation.

### 03 — Jenkins CI/CD

Introduction to Continuous Integration and Continuous Delivery.

**Focus:** Jenkins, pipelines, Jenkinsfiles, builds, testing and automated deployments.

### 04 — Terraform Fundamentals

Introduction to Infrastructure as Code.

**Focus:** Terraform, HCL, providers, resources, variables, outputs, state and Azure infrastructure.

### 05 — Terraform Advanced

Build more reusable and maintainable infrastructure.

**Focus:** modules, `for_each`, `count`, expressions, state management, lifecycle and best practices.

### 06 — Docker & Kubernetes

Introduction to containers and container orchestration.

**Focus:** Docker, images, Dockerfiles, registries, Kubernetes, pods, deployments and services.

### 07 — Integration

Bring the technologies together into a working DevOps workflow.

**Focus:** Git → Jenkins → Docker → Registry → Kubernetes

> This exercise will be completed **without Terraform**, focusing on the application delivery workflow.

### 08–09 — Hackathon

Independent challenge applying the skills developed throughout the programme.

Trainees design and build their own solution using the technologies covered.

**Focus:** problem solving, automation, CI/CD, containers, deployment, troubleshooting and technical decision-making.

### End Goal

By the end of the programme, trainees should understand not just individual DevOps tools, but **how they work together to automate the journey from source code to a running application.**
